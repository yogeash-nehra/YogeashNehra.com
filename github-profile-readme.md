### 🚀 About Me

I'm a Computing Systems graduate (Unitec Institute of Technology) now working as a **Graduate Software Engineer at Aderant**, building enterprise features, resolving defects, and shipping QA-ready code. Before that, I ran full-stack and cloud projects as a Software & IT Consultant, and started out in IT support automating infrastructure with PowerShell and Azure AD.

I build across the stack — React front ends, .NET/C# and Python back ends, AWS and Azure infrastructure — with a growing focus on **agentic AI tooling** that plugs directly into real developer workflows.

- 🔭 Currently building an **agentic AI bug-fixing tool** at Aderant that analyses issues across enterprise codebases and automates reusable fix workflows
- 🌱 Deepening my AWS/Azure cloud and Kubernetes/Terraform skills
- 🛰️ Shipped **PiLot**, an autonomous UGV with real-time telemetry, sensor data, and obstacle avoidance — awarded Best Project at the Unitec Showcase
- ⚡ Led a serverless GenAI chatbot (AWS Lambda, Bedrock, API Gateway) at a 24-hour AWS Hackathon
- 💬 Speak te reo Māori and I'm an active Toastmasters member
- 📫 Reach me at **info@yogeashnehra.com** or on [LinkedIn](https://www.linkedin.com/in/yogeash-nehra/)
